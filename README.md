# SIM-Barang
## Sistem Pengelolaan Inventaris Barang Jurusan

### Deskripsi Proyek
SIM-Barang merupakan aplikasi berbasis web yang dirancang untuk membantu pengelolaan inventaris barang di lingkungan jurusan. Aplikasi ini bertujuan mempermudah pencatatan, pemantauan, dan pengelolaan data barang.

### Tujuan
- Mengelola data inventaris barang.
- Mencatat barang masuk dan barang keluar.
- Memantau jumlah dan kondisi barang.
- Mempermudah pencarian informasi inventaris.

### Teknologi yang Digunakan
- HTML5
- CSS3
- JavaScript
- PHP Native
- MySQL
- Laragon
- Visual Studio Code
- Git dan GitHub

### Konsep HTTP Request dan HTTP Response

**HTTP Request**

HTTP Request adalah permintaan yang dikirimkan oleh client (browser) kepada server untuk memperoleh atau mengirimkan informasi.

Contohnya, ketika pengguna membuka halaman SIM-Barang melalui browser, browser mengirimkan permintaan kepada server.

**HTTP Response**

HTTP Response adalah tanggapan yang diberikan oleh server setelah menerima dan memproses permintaan dari client.

Contohnya, server mengirimkan halaman web SIM-Barang kepada browser sehingga halaman dapat ditampilkan.
